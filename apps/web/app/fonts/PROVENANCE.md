Unmodified Myanmar-subset WOFF2 regular (400) and bold (700) from the pinned
@fontsource/noto-sans-myanmar 5.3.0 package, Google Fonts version v27.
Source: https://registry.npmjs.org/@fontsource/noto-sans-myanmar/-/noto-sans-myanmar-5.3.0.tgz
Upstream: https://github.com/notofonts/myanmar
Package and asset SHA-256 values are recorded in provenance.json.

These binaries are bundled in the viewer Next.js application.
next/font/local emits same-origin hashed assets; there is no runtime Google Fonts
request or reliance on an operating-system font. Only the Myanmar subset is
bundled, so Latin interface text retains its existing Arial fallback.

Chromium tests inspect actual platform font selection through the DevTools
Protocol. Windows user-agent and mobile viewport emulation on Linux do not
replace native Windows Chromium, physical Android or Myanmar reader acceptance.
